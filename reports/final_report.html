3 Remediation

3.1 Scenario 1 — Network Security Config + Certificate Pinning

Ap dung res/xml/network_security_config.xml: cleartextTrafficPermitted="false", chi trust <certificates src="system"/>, va Certificate Pinning voi SHA-256 pin tu server_hard.js.
Ket qua: App nem SSLHandshakeException — 0 byte bi intercept.

3.2 Scenario 2 — Secure Storage + Strong JWT + Root Detection

(a) Xoa token.txt, luu token bang EncryptedSharedPreferences (AES-256-GCM, Android Keystore).
(b) server_hard.js dung crypto.randomBytes(32) thay secret co dinh — token expiry 15 phut.
(c) Root Detection: kiem tra /sbin/su, Build.TAGS test-keys → finish().
